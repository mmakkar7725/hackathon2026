AI Agent Architecture
Orchestrator

AgentOrchestrator

Coordinates agents in sequence, manages pipeline state, routes data between agents.

Data Agent

DataIngestionAgent

Handles PDF/image/text parsing. Falls back to rule-based when Gemini unavailable.

NLP Agent

NLPAgent

Extracts medical concepts, maps to ICD-10/SNOMED using dictionary + Gemini disambiguation.

Query Agent

QueryExecutionAgent

Generates, refines SQL. Executes vs in-memory dataset. Produces near-miss analysis.
